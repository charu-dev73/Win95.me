# Win95.me

A small front-end practice project inspired by the classic Windows 95 desktop.

I built this to practice HTML and CSS while trying to recreate the look and feel of an old-school Windows desktop.

## Built With

- HTML
- CSS
- No JavaScript
- No frameworks

## Features

- Windows 95-style desktop
- Interactive windows
- Start menu
- Taskbar
- CSS-only popups
- Retro CRT effect
- Music player
- Projects window
